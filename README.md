# NPC-E-Inimigos

Projeto independente para estudar e desenvolver um modo de jogo de Swordigo no qual NPCs e criaturas possam ser controlados pelo jogador.

## Documentação adicionada
- [Análise de comportamento e viabilidade](docs/ANALISE_COMPORTAMENTO_E_VIABILIDADE.md)
- O inventário detalhado dos 81 templates foi gerado em CSV e entregue junto ao relatório no chat.

## Estado real
Esta etapa registra pesquisa e arquitetura. **Ainda não existe APK independente jogável**: é necessário implementar e testar a conversão dos templates de IA para o controlador do jogador, incluindo movimento, colisão, animações, combate, habilidades e câmera.

## Próxima etapa
Criar um protótipo de personagem controlável com um rig compatível (primeiro candidato: `skelly_dw`) e validar em runtime Android ARM64 antes de expandir para outras famílias.
