# Patches do Swordigo original

As mudanças serão guardadas como diferenças pequenas e reproduzíveis aplicadas aos arquivos da versão original.

- A entrada original é `Swordigo.apk`, fornecida pelo usuário.
- Use `scripts/prepare_original_game.py` para validar a origem e extrair os recursos para `build/original/`.
- Não copie APK/APKM, modelos, texturas ou sons comerciais para esta pasta nem para o repositório público.
- Um patch de controle só deve ser adicionado aqui depois de implementado e testado no runtime original.

**Estado:** ainda não há patch funcional de conversão de NPC para jogador. O objetivo permanece controlar os NPCs/inimigos dentro do Swordigo original, não iniciar um jogo novo.
